# Ateliê Digital · Vitrine pública

Cópia portátil da vitrine independente. Use Node.js 24 e npm em um ambiente autorizado.

1. SHA256SUMS.txt é um manifesto histórico da transferência; arquivos alterados após a extração podem não corresponder a ele, portanto não representa hashes atualizados do código.
2. Execute npm ci, npm test e npm run build:vitrine.
3. Execute npm run audit:vitrine para conferir a estrutura e os hashes de dist-vitrine/.

O acervo mostra projetos demonstrativos e capas gráficas. O atendimento comercial está em configuração. A tipografia usa Google Fonts, com fontes de sistema como fallback.
